# JUE BABY LOTTERY

蓝色 boy / 粉色 girl 双池互动网页原型。打开 index.html 即可运行，不需要安装依赖。

## 已有功能

- 默认头像选择、昵称编辑。
- 圆形头像漂浮、点击查看昵称、入池动画。
- 加入、切换池子与本机计数联动。
- localStorage 保存当前浏览器的资料和选择。
- 手机与桌面布局。

## 当前状态

**这是演示版，尚未接入多人共享后端。**

两个池子从 0 人开始，没有示例成员；首次选择头像并手动填写微信昵称，加入后仅当前浏览器计数增加。其他人的加入不会同步。没有真实微信授权，也没有上传照片功能。

真实多人版本仍需接入身份识别与云数据库，由服务端保存成员并保证重复加入不重复计数。
