# JUE BABY LOTTERY

在线访问：https://leevengu1215-arch.github.io/jue-baby-lottery/

## 真实多人同步

页面由 GitHub Pages 托管；共享 API 与 D1 数据库运行在已部署的云服务上。GitHub Pages 本身不运行数据库。

- 初始人数为 0，没有示例成员。
- 首次选择一个默认头像并手动填写微信昵称；取消可查看池子。
- 确认资料不会增加人数，选择 boy / girl 加入后才计数。
- 同一身份重复加入不重复计数；换池更新同一条记录。
- 加入后可点击「退出池子」，撤回加入并保留头像昵称。
- 其他人的头像与人数每 5 秒刷新，后台标签页暂停轮询，回到页面立即刷新。
- 每池最多显示 12 个头像，人数统计全部成员；自己的头像保留在可见列表中。
- 姓名、头像与池子选择保存于云端，刷新后从服务器恢复。
- 云端不可用时提示重试，不用本地虚构人数代替。

## 身份说明

没有接微信授权或实名登录。昵称由本人填写，头像为六个默认选项。浏览器保存随机匿名身份凭据，服务端仅存凭据摘要；公开接口不返回该凭据或摘要。

同一浏览器保持身份，换设备、无痕窗口或清除站点数据会产生新身份。因此保证的是「每个浏览器身份一条记录」，不是「每个自然人一次」。

加入后头像和昵称对访客可见。未加入的资料不出现在公共列表里。请勿填写敏感信息。

## 文件

- `index.html`：网页样式与结构。
- `app.js`：资料确认、成员显示与云端同步。
- `avatar.png`：头像设计。
- `backend/worker.js`：共享 API 源码，带输入校验、来源限制、身份校验和参数化 SQL。
- `backend/db/`、`backend/drizzle/`：数据库定义与迁移。

后端部署与 GitHub Pages 分开管理：本仓库的后端目录只公开源码，推送到 GitHub 不会自动部署 API。API 使用云运行环境提供的 `DB` 绑定。修改数据库时生成新迁移，勿修改已部署迁移。仓库不含密钥和用户数据。

## 已验证

真实云端、两个独立浏览器身份、GitHub 页面来源下的跨域连接、加入/换池、人数/头像同步、刷新恢复。临时测试成员已删除。

## 手机连接提示

网页和云 API 使用不同域名。出现连接失败时，可能是网络或浏览器无法访问云服务；桌面测试通过不代表所有手机网络均可访问。页面提供中文错误提示和重试，不会在请求失败时伪造成功。
